## 3. 数据准备入口与防覆盖

历史数据依赖链依次为：`download_sft_raw.py` → 旧 `prepare_sft_data.py` 生成旧划分和 `prepare_metadata.json` → `prepare_sft_data_sepfix.py` → `prepare_rl_data.py`，均位于 `scripts/local/`。旧准备脚本使用错误分隔符，仅用于说明历史依赖，不能把其输出作为新的修正版训练数据。旧 `train_sft.py` 也不作为修正版训练入口。

修正版 SFT 数据准备脚本会读取旧目录中的 `raw.json` 与 `prepare_metadata.json`，固定 tokenizer revision，并核验输入哈希。它不是从空目录即可独立运行的程序。现有输出已齐全，不需要再次准备；脚本遇到输出已存在时会拒绝覆盖。

若迁移到新机器，需要明确导入旧数据来源记录，或将脚本改为显式接收输入、输出目录后重新验证。不能为了绕过保护直接删除已有实验数据。`scripts/local/` 中若干脚本仍固定了实验路径；这一点是待完善的可移植性限制。

具体前置条件：`data/gsm8k_test.json` 必须已按原格式准备；修正版准备脚本还需要原 `raw.json`、旧 `prepare_metadata.json` 和缓存中的指定 tokenizer revision（它设置了 `local_files_only=True`）。RL 准备脚本实际读取旧 `tinygsm_sft_pilot/train.json` 和 `valid.json` 做排除；本次旧／新划分哈希一致，但换数据后不能假定仍然等价。数据下载与旧准备脚本通过 HfApi 获取当时最新 revision，今天直接重跑可能变化；精确复现应固定记录版本或取得原始文件，并验证哈希。上述数据文件已附在 `项目源码/data/` 中，但 tokenizer 缓存需自行准备；以上依赖链不是从空目录可直接运行的命令清单。

## 5. 固定 checkpoint 的统一测试命令

下面函数只负责推理和评分，不训练。调用示例固定使用本报告的 RL checkpoint。它会新增测试结果，不覆盖已有记录；本轮模型已评估过，不必重复执行，也不应根据新测试结果回头挑模型。

```bash
cd /home/chen/projects/s-flm
conda activate sfm
set -o pipefail
export CC=/usr/bin/gcc
export CXX=/usr/bin/g++
export TOKENIZERS_PARALLELISM=false

evaluate_fixed_checkpoint() {
  local checkpoint_path="$1"
  local experiment_label="$2"
  local output_path="$PWD/eval_runs/${experiment_label}_$(date +%Y%m%d_%H%M%S_%N)"

  if [ ! -f "$checkpoint_path" ]; then
    echo "Checkpoint missing: $checkpoint_path"
    return 1
  fi
  mkdir -p "$output_path"

  TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1 python -u -m main \
    mode=gsm8k_eval seed=1 \
    eval.checkpoint_path="$checkpoint_path" \
    data=gsm8k-test \
    data.data_path="$PWD/data/gsm8k_test.json" \
    data.cache_dir="$PWD/data_cache/gsm8k_full" \
    data.tokenizer_name_or_path=HuggingFaceTB/SmolLM-135M \
    model=small model.length=512 algo=mdlm \
    sampler=ancestral sampler.steps=32 \
    loader.eval_batch_size=2 loader.num_workers=1 \
    trainer.num_nodes=1 trainer.devices=1 \
    gsm8k.output_dir="$output_path" \
    +wandb.offline=True hydra.run.dir="$output_path" \
    2>&1 | tee "$output_path/console.log"
  local run_status=$?
  echo "Evaluation exit code: $run_status"
  echo "Results: $output_path"
  return "$run_status"
}

evaluate_fixed_checkpoint \
  "$PWD/outputs/rl_pilot64_20261022_174012_898690/group016.ckpt" \
  "mdlm_rl_fixed32"
```

缓存目录只适用于此次已核对的完整测试输入。更换数据文件、分隔符或 tokenizer 时，应使用独立缓存目录，以免误用旧前缀。
